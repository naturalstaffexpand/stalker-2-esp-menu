## 🧩 About

**STALKER 2 overlay Menu** is a curated list of STALKER 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap viewer, entity tracker
- **Quality-of-Life Helpers** — inventory catalog, item manager, overlay notes
- **Research Notes** — anomaly layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- **Entity Tracker** — visualize NPCs, mutants, and items through walls for study
- **Minimap overlay** — extended minimap with entity markers
- **Loot Highlighter** — highlight containers and lootable items
- **Path Notes** — record and review movement routes for research
- **Speed Control** — adjust game speed for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- **Inventory Catalog** — browse items, weapons, and armor
- **Custom Skin Notes** — organize player cosmetics
- **HUD Customizer** — adjust HUD elements for clarity

### 🏋️ Practice Layout
- **Anomaly Map Notes** — segment study on any anomaly field
- **Gravity Flip Control** — manually switch gravity mid-air for testing
- **Jump Buffer Notes** — chain complex maneuvers in the editor

## 🛠️ Troubleshooting

If the overlay does not appear, ensure the game is running in windowed or borderless mode. Some antivirus software may flag the helper; add an exclusion if you trust the source. For performance issues, lower the overlay refresh rate in the config. If the menu hotkey conflicts, change `menu_hotkey` to another key such as `F1` or `Insert`.
